Real-time social listening

Listen together, perfectly in sync.

Crate turns Spotify listening into a shared, live session. Host a room, let friends vote on what plays next, and build a sound profile from what you actually listen to, not a survey you filled in once.

Features

Four screens, one live session.

Everything in Crate is built around a room that stays in sync, not a feed you refresh.

Radar

Live jam rooms and friends surface the moment they go active, so joining a session already in progress is one click away.

Jam Room

Anyone in the room can queue a track. Upvotes move it up the line, and the host's playback stays the source of truth for every listener.

Sound profile

Energy, valence and danceability are averaged from Spotify's own audio features across the tracks you queue, alongside your most played tracks and artists.

Security

Spotify tokens are encrypted at rest with AES-256-GCM, OAuth state is HMAC-signed and expires after ten minutes, and only a room's host can broadcast sync events.

Interface

Built like desktop software, not a webpage.

The window itself never scrolls, individual panes do. Radar shows what's live, Jam Room is the shared queue, and Analytics turns raw listening into a profile.

How it works

From sign-in to synced playback.

01

Sign in with Google, verified through Firebase Authentication.

02

Link Spotify Premium. Playback runs through the Spotify Web Playback SDK, which requires Premium.

03

Start or join a room from Radar, and it becomes your active Jam Room.

04

Queue and vote. Playback position is projected and corrected continuously, so everyone hears the same moment.

Stack

What it's actually built with.

Frontend
React 19 Vite Tailwind CSS 4
Backend
Express and Socket.io in a single process, with Vite running in middleware mode during development.
Database
PostgreSQL via Drizzle ORM, works against Neon or any managed provider.
Auth
Firebase Authentication with Google sign-in, verified server side with the Admin SDK.
Playback
Spotify Web Playback SDK. Requires a Spotify Premium account.
Testing
Node's built in test runner, 24 tests covering token encryption, OAuth state and playback position projection.
