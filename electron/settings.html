Crate desktop — first-run setup

Before Crate can start it needs the same backend settings as the web app: a PostgreSQL database, a Firebase project (Google sign-in + Admin SDK), and a Spotify application. These are kept only on this computer in %APPDATA%/crate-config/settings.json. See docs/desktop.md in the repository for how to obtain every value.

PostgreSQL
Firebase (Admin SDK service account)
Spotify

Tips: generate APP_SECRET with node -e "console.log(require('crypto').randomBytes(32).toString('hex'))". Run migrations against your database once with npm run db:migrate.
